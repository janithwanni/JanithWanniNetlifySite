Research

I am a PhD candidate in the Department of Econometrics & Business Statistics at Monash University. I work on explainable AI, data visualisation and interpretable models, and I build open-source R packages along the way.

Projects

kultarr: Anchors, revisited

A pure-R implementation of Anchors that you can debug and visualise. It uses S7 classes, memoised rewards and parallel search, and includes helpers for drawing anchors in high dimensions.

R package · in development

Docs

kumquat: a simpler LIME

A transparent take on LIME for tabular data. It returns the perturbations, predictions and local GLM, so you can audit exactly how an explanation was built.

R package · CRAN

Docs · CRAN

sillysplines: drawn decision boundaries

An interactive widget for sketching a linear-spline decision boundary and downloading the coordinates as a synthetic classification dataset, for teaching and model testing.

R package · htmlwidget

Docs

clamp-maker: sawtooth data in the browser

A Svelte app that runs R in the browser through webR. Sliders set the rotation, overlap, label noise and train/test split of a two-class dataset with a sine-wave boundary, and you can download the result as CSV. It came before sillysplines and is what led to it.

Svelte · webR

Site · GitHub

scatteR: inverse scagnostics

My undergraduate thesis. It generates scatterplots that match target scagnostic measures by placing points with simulated annealing, which gives data for testing visual and ML methods.

R package · CRAN · useR! 2022
